# Mi Mai

MaiBot 米家第三方插件。通过米家扫码登录读取设备状态，并在侧栏 WebUI 中配置别名、设备类别、设备/场景白名单、自然语言控制权限和用户白名单。

## 安装

在 MaiBot 使用的 Python 环境中安装米家 API 依赖，然后重启 MaiBot：

```powershell
python -m pip install -r plugins/mi_mai/requirements.txt
```

插件首次加载后，在 MaiBot 侧栏打开 **Mi Mai**，点击“扫码登录”。登录后点击“读取设备状态”，为要控制的设备填写别名和类别，再加入白名单。场景也需要单独加入白名单。

## 默认权限

- 设备状态和设备列表为只读工具，默认可用。
- 自然语言设备控制、场景控制默认关闭。侧栏开关点击后立即生效；开启时会出现后果确认警告，关闭时直接生效。
- SDK 组件启停与运行时权限检查同时生效；即使工具列表刷新失败，后端仍拒绝未启用的控制请求。
- 用户白名单限制默认开启。添加 `平台:用户ID`，例如 `qq:123456`。关闭此限制后，所有用户都能控制已加入设备/场景白名单的目标。
- 设备和场景的白名单始终有效；关闭用户限制不会绕过目标白名单。
- WebUI 的手动操作也仅对设备/场景白名单中的目标开放，并在执行控制或场景前再次确认。
- 云端手动控制在后台执行，页面状态会显示操作与刷新进度。

工具错误、权限拒绝和工具未启用时，面向对话的结果使用自然口吻，不包含异常细节；诊断信息写入插件日志。用户身份无法从可信消息上下文中解析时，默认按未授权处理。

## 指令

```text
/mimai 列表
/mimai 状态 <设备别名或名称>
/mimai 开 <设备别名>
/mimai 关 <设备别名>
/mimai 操作 <设备别名> <动作名> [JSON参数]
/mimai 场景 <场景名称>
```

开关指令只适用于设备规格中存在可写 `on`、`power`、`switch` 属性，或描述为“开关”的设备。侧栏和 LLM 工具也支持按设备规格设置其他可写属性，或以 JSON 数组参数运行 MIoT 动作。

## MaiWeave 联动

默认关闭。启用后插件调用 MaiWeave 的 `ilworkcn.maiweave.evaluate_behavior` 只读 API，使用 `behavior="proactive"`；当返回明确的 `defer` 且原因是 `sleeping` 或 `busy` 时，设备和场景控制会暂缓。API 不可用或状态不明确时，不拦截控制。

## 数据与隐私

登录令牌和本插件设置只保存在 MaiBot 为插件提供的 `ctx.paths.data_dir` 下，不写入主程序配置文件。插件不会把令牌放入 WebUI 查询结果或 LLM 工具结果。

## 兼容性与验证

清单声明 MaiBot `1.4.5` 至 `1.4.99`、SDK `2.22.1` 至 `2.23.99`。MaiBot 清单要求有限的最高兼容版本；这个声明不能证明未来 Host/SDK 均兼容，也不能覆盖超过清单上限的版本。升级后应运行插件加载、侧栏扫码、设备刷新、白名单拒绝/放行、属性控制和场景控制验收。

当前源码工作区不包含 MaiBot 安装或 SDK，因此本地测试覆盖策略逻辑和语法检查；真实扫码与云端设备操作仍须在目标 MaiBot 实例上验证。

## 本地测试

在项目根目录运行：

```powershell
python -m unittest discover -s plugins/mi_mai/tests -v
python -m compileall -q plugins/mi_mai
```
